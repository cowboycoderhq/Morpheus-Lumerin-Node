The Windows release is a single **portable executable**. On first launch, the app downloads and manages its own services — proxy-router, `llama.cpp` AI runtime with the `Qwen2.5-1.5B-Instruct` demo model, and an IPFS node (kubo) as an optional service. For source builds, see [macOS install](/consumers/install/macos) and adapt the toolchain — but note that this fork publishes no Windows proxy-router binary, so a from-source build installs cleanly and then hangs on the first-run wizard with no error (`ui-desktop/.env.example:57-64`). The portable executable above is unaffected: CI injects a real per-platform download URL.

## Steps

<Steps>
  <Step title="Download">
    Get the **latest** portable executable from [Releases](https://github.com/MorpheusAIs/Morpheus-Lumerin-Node/releases) — the asset is named like `win-x64-morpheus-app-<version>.exe`. The **release tag** carries a branch suffix for non-mainnet builds (`VTAG=v${VFULL}-${RNAME}`, `.github/workflows/build.yml:283`), but the **asset filenames do not** — they use the bare version (`build.yml:3027,3091,3155,3220,3305`). Identify a testnet build by the release it hangs under, not by the filename.
  </Step>
  <Step title="Launch">
    Double-click the `.exe`. Windows Defender may prompt — allow it.
  </Step>
  <Step title="Let the app fetch its services">
The first launch (and the first after each update) shows a setup wizard titled **Setting up your AI assistant** (`SetupWizard.tsx:293`, which replaced the older "Starting services" list): the app downloads the proxy-router first, then optional AI runtime, demo model, and an IPFS node (kubo) as an optional service, and starts the **Proxy Router** before optional services. Local AI Runtime can fail on some Windows setups (e.g. ARM Parallels without AVX2) without blocking onboarding — use remote models, or **Continue anyway** / **Try again** as needed. **Container Runtime** (Docker) is only detected, never installed.
  </Step>
  <Step title="Onboard">
    Accept terms, set a UI password, create or recover a wallet. Save the mnemonic somewhere safe.
  </Step>
  <Step title="Validate">
    Open `http://localhost:8082/swagger/index.html`. For Swagger **Try it out**, click **Authorize** and use the proxy-router `.cookie` credentials ([API auth](/reference/api-auth)). In the Chat tab, click **New chat** and pick the model under the **Local** section to verify the local pipeline.
  </Step>
</Steps>

## Cleanup

<Warning>
**Save your wallet mnemonic / private key first.** This deletes the local key store along with the downloaded services.
</Warning>

```cmd
rmdir /s /q %APPDATA%\morpheus-app
rmdir /s /q %LOCALAPPDATA%\morpheus-app
```

(`morpheus-app` is the Electron package / `userData` folder name; the product name in the UI is **MorpheusUI**.)

See also: [Troubleshooting](/reference/troubleshooting).
