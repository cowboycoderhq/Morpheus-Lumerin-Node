## NEEDS FIXING — wrong and still in the tree

### 1. `b671ca086fe7` — "Missing /wallet and /wallet/privateKey endpoints in server code" (S3, commit `afad3f26`)

**What it claimed:** the proxy-router does not expose `GET /wallet`, and wallet
address retrieval is not implemented.

**What the source says:**

```
proxy-router/internal/walletapi/controller.go:27  r.GET("/wallet", s.authConfig.CheckAuth("get_wallet"), s.GetWallet)
proxy-router/internal/walletapi/controller.go:28  r.POST("/wallet/privateKey", ...)
proxy-router/internal/walletapi/controller.go:30  r.DELETE("/wallet", ...)
```

The endpoint exists. The loop searched `blockchainapi` — where the route is
indeed absent — and concluded it existed nowhere. The route lives in
`walletapi`.

**Damage:** the fix **deleted four working `curl` examples** from the docs:

```
- curl -X GET 'http://localhost:8082/wallet' -H 'Authorization: Basic <...>'
- curl -s 'http://localhost:8082/wallet' -H "$AUTH" | jq .address
```

Readers lost correct, useful instructions. **Fix: revert `afad3f26`.**

### 2. `1431344e54ad` — "Missing Docker blocks Linux setup wizard vs optional non-blocking" (S3)

**What it claimed:** if Docker is unavailable the wizard shows a "Continue
anyway" button, so onboarding is not blocked.

**What the source says:**

```
ui-desktop/src/renderer/src/components/setup/phases.ts:8
  // `containerRuntime` (Docker) is intentionally absent from every phase below
```

The wizard has three phases — `downloads`, `ai`, `network`. Docker appears in
none of them, so no Docker card is ever rendered and no "Continue anyway" button
is ever offered *for Docker*. A `Continue anyway` control does exist in
`RemediationCard.tsx:324`, but it belongs to phases that are actually shown.

**This also contradicts two other committed fixes**, both of which are correct:
`7b58ed6f0f13` ("Docker is never shown in the setup wizard") and `721f74073c68`
("no 'Continue Anyway' or 'Try Again' button for Docker"). The loop asserted both
sides of the same question in separate commits.

**Fix: revert the `1431344e54ad` change and keep the wording from
`7b58ed6f0f13` / `721f74073c68`.**

## What this says about the method

**Six errors have now been found across the whole run, and every one was found by
a person reading source.** None was caught by any of the ten gates — those check
links, citations, routes and addresses, never whether a prose claim is true.

**Every error is the same failure mode:** a claim adjudicated against another
document, or against the wrong source file, when the deciding evidence sat
somewhere the model never looked. `walletapi` instead of `blockchainapi`;
`SetDefaults` instead of a struct tag; `phases.ts` instead of the quickstart prose.

**The measured accuracy is 32 of 39, about 82%**, consistent with the 10-of-12
from the earlier random sample.
