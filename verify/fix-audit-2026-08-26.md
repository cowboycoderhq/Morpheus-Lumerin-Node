**The rate did not measurably get worse.** 21.2% against a 13.5% baseline looks
like a jump, but the intervals overlap across most of their range, and the two
numbers were not produced by the same instrument: the baseline was one hand pass,
this was six dedicated reviewers each reading source for a six-commit slice. A
more sensitive instrument finding more defects is the expected result, not
evidence of decline. Treat the **pooled 17.1%** as the working figure — roughly
**one committed fix in six states something false**.

That number is what should govern how much of this branch may be trusted
unattended. It is not low enough to stop auditing.

## The two patterns, both mechanizable

**1. The default that is not in `SetDefaults`.** Four of the false claims are one
mistake: the loop read `func (cfg *Config) SetDefaults()`, found no entry, and
concluded "no default exists." The fallback lives at the **consumption site**
instead — `if x == 0 { x = DefaultX }` inside a constructor. `check-mechanized.mjs`
already knew about this blind spot and filed such fields as UNDETERMINED, which is
silent. **Now guarded** by `check-constructor-defaults.mjs` (`7f842467`), which
resolves constructor fallbacks and rejects any doc stating the sentinel — in value
or in prose. Proven by firing against the pre-repair tree.

**2. Fixing the wrong artifact.** `5fc8effd` edited a `-h` transcript instead of
`cli/main.go:233`; `be879b7f` edited troubleshooting prose instead of
`.env.example:44`; `29db48fc` wrote the defect into the file's own header instead
of adding the five missing variables; `631adde1` edited the consumer page for a
finding about a provider file. Not yet guarded.

**3. The enumerate step under-counts paraphrases.** Repeatedly, the fix landed on
the sentence the finding quoted while a restatement of the same falsehood sat in
the next line or the same table cell. The existing `partial` gate is advisory only.
