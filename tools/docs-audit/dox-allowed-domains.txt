# Email domains this repository publishes ON PURPOSE.
#
# check-dox blocks on every email address it finds in the files and the commit
# metadata a branch would publish. Exactly one identity is meant to be there: the
# pseudonymous one this history already commits under, which is public in every
# commit's author field and in two of the handoff documents in verify/.
#
# WHY THIS IS A FILE, AND A TRACKED ONE.
#
# The allowance used to be read from `git config user.email`, i.e. from whatever
# machine the gate ran on. On a CI runner actions/checkout sets no user.email, so
# the allowance was empty and EVERY author and committer address in the range
# became a BLOCK hit — 454 of them across the audit range, on commits that are
# exactly as intended. A gate that fails on the identity it is supposed to permit
# gets ignored, which costs more than the check is worth.
#
# The alternatives were worse in the other direction. Taking the allowance from
# the addresses IN the commits under test allows every address to allow itself.
# Taking it from the merge-base commit is not circular, but it widens the
# allowance to whatever domain that commit used: on a pull request against an
# upstream repository that is a stranger's domain, and if it is a public mail
# provider it would admit the operator's real address while still blocking the
# pseudonym this branch commits under.
#
# So it is declared here, by a person, where widening it is one visible line in a
# diff instead of an inference nobody sees.
#
# Format: one domain per line, '#' begins a comment, a leading '@' is optional.
# DOX_ALLOW_DOMAINS=<comma-separated> adds to this list for a single run.
